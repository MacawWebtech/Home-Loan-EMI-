Ledgerline template guide

Introduction

Ledgerline is a static, multi-page HTML template for a home loan EMI and financial planning consultancy. It uses Bootstrap 5.3.3, one custom stylesheet with design tokens, and three vanilla JavaScript files. There is no build step.

HTML pages29
Calculators5
DependenciesBootstrap only

Installation

  1. Unzip the package. Keep the folder structure as it is.
  2. Open index.html in a browser. Everything works from disk, including the calculators, theme and RTL toggles.
  3. For local development, serve the folder so paths behave like production:
npx serve .
# or
python3 -m http.server 8080
  1. To publish, upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, cPanel).
  2. Custom 404: copy pages/404.html to the root as 404.html and change ../ asset paths to ./.

Why classic scripts instead of ES modules? Browsers block type="module" scripts on file:// URLs. The JS is written in modern ES6+ and organised into module objects on one window.LL namespace, so it runs when opened straight from disk. If you add a bundler later, each section converts cleanly to an export.

Sticky header → hero with live mini calculator → trust strip (count-up) → What we do → Your loan journey → Who is this for → Lender comparison preview → Client portal teaser → Testimonials → FAQ → CTA band → Newsletter → Footer with regulatory disclaimer. Each section has one primary action.

Page anatomy

Every public page uses the same shell: skip link, header.ll-header, main#main, footer.ll-footer. Inner pages start with .ll-page-head (breadcrumb, eyebrow, one H1, lead). Dashboards use .ll-app → aside.ll-sidebar + .ll-topbar + main.ll-app-content.

Customizing colors

All colors are CSS custom properties at the top of assets/css/style.css. Components only read tokens, so changing a token updates the whole site. 

:root {
  --ll-primary: #1c2b45;   /* ink-navy: headings, dark bands, footer */
  --ll-secondary: #5b6b82; /* slate */
  --ll-accent: #a84c25;    /* copper: primary buttons, highlights */
  --ll-accent-rgb: 180, 83, 42;  /* keep in sync with --ll-accent */
  --ll-success: #3f7356;   /* sage: approved, savings */
  --ll-warning: #9a6a12;
  --ll-bg: #f7f2e8;        /* paper cream */
  --ll-surface: #fffdf8;   /* cards */
  --ll-text: #1d2433;
}

Dark mode values live in assets/css/dark-mode.css under [data-theme="dark"]. Change both files together. Text and button combinations were chosen for WCAG AA contrast; re-check with a contrast tool if you change them.

Customizing fonts

The template uses three Google Fonts: Fraunces (headlines), Manrope (body) and JetBrains Mono (all money figures, for aligned tabular digits). To swap them, edit the Google Fonts <link> in each page head, then the tokens: 

:root {
  --ll-font-display: "Fraunces", Georgia, serif;
  --ll-font-body: "Manrope", system-ui, sans-serif;
  --ll-font-mono: "JetBrains Mono", ui-monospace, monospace;
}

Any element with .ll-money, .ll-num or [data-money] uses the mono font with tabular numbers.

Currency & number format

Change currency once in assets/js/main.js. Every calculator, slider label, count-up and [data-money] element re-renders with it. 

const CONFIG = Object.assign({
  locale: 'en-IN',      // 'en-US', 'en-GB', 'ar-AE' …
  currency: 'INR',      // 'USD', 'GBP', 'AED' …
  shortUnits: 'indian'  // 'indian' → ₹50 L / ₹2.5 Cr ; 'western' → $50K / $2.5M
}, window.LL_CONFIG || {});

You can also override it per page without editing the file:

<script>window.LL_CONFIG = { locale: 'en-US', currency: 'USD', shortUnits: 'western' };</script>
<!-- place before main.js -->

Static amounts in HTML are written as <span data-money="5000000">₹50,00,000</span>. The text is a no-JS fallback; JS reformats it. Add data-money-short for the compact form. Slider ranges such as the 5 L–5 Cr labels are plain text, so update them by hand if you change markets.

Editing content

  • Text: edit the HTML directly. Section comments like <!-- ===== D. JOURNEY ===== --> mark each block on the home page.
  • Jargon tooltips: wrap a term as <span class="ll-term" tabindex="0" data-bs-toggle="tooltip" data-bs-title="Plain explanation">LTV</span>. They open on hover and keyboard focus.
  • Lender table: sample lenders are fictional. Replace names, rates and fees, and keep the disclaimer under the table.
  • Images: see Photos below.
  • Counters: <span data-count="500" data-prefix="currency" data-suffix=" Cr+"> counts up when scrolled into view. data-decimals sets precision.
  • Legal: search TODO (legal) for licence numbers and regulator wording.

Calculators

All maths is in LL.calc (assets/js/calculator.js) and uses the standard reducing-balance formula: 

EMI = P × r × (1 + r)^n / ((1 + r)^n − 1)
P = principal, r = annual rate / 12 / 100, n = months

LL.calc.emi(5000000, 8.5, 240)            // 43391.16
LL.calc.principalFromEmi(43391.16, 8.5, 240) // 5000000
LL.calc.schedule(P, rate, n, { extraMonthly, lumpAmount, lumpMonth })
LL.calc.yearly(rows)
Calculator Hook Inputs (data-k)
Hero mini [data-mini-calc] amount, rate, tenure (years)
EMI + schedule [data-calc-form="emi"] amount, rate, tenure
Prepayment [data-calc-form="prepay"] amount, rate, tenure, extra, lump, lumpYear
Affordability [data-calc-form="afford"] income, existing, savings, rate, tenure, foir
Balance transfer [data-calc-form="transfer"] outstanding, remaining, oldRate, newRate, fee

Outputs are any element with data-out="key". A range and a number input with the same data-k stay in sync. The hero calculator passes its values to the full calculator via ?amount=&rate=&tenure=. Affordability uses RBI LTV bands (90% ≤ ₹30 L, 80% ≤ ₹75 L, 75% above); edit ltvFor() for other markets.

Dark mode & RTL

Dark mode follows the system setting until the visitor clicks the toggle; the choice is then saved in localStorage (ll-theme). A tiny inline script in each <head> applies it before first paint to avoid a flash.

RTL: the toggle sets dir="rtl", swaps bootstrap.min.css for bootstrap.rtl.min.css and saves the choice (ll-dir). Custom CSS uses logical properties (margin-inline-start, inset-inline-end…), so most layout flips by itself; rtl.css handles icons, transforms and keeps money figures and sliders LTR. To ship an Arabic or Hebrew site, set <html lang="ar" dir="rtl">, point #bs-css at the RTL file, and add a suitable font in rtl.css.

Forms & validation

Add data-validate to any form. Fields use native constraints (required, type="email", pattern, minlength) and get friendly inline messages, linked with aria-describedby. Override any message per field: 

<input required pattern="[0-9+ ]{10,15}"
       data-msg-required="Please add your number."
       data-msg-pattern="Use a 10-digit mobile number.">
<input id="pw2" data-match="pw1" data-msg-match="Passwords don't match yet.">

Other form attributes: data-toast (success message), data-redirect (go to a page on success), data-success (id of an element to reveal).

Accessibility

  • Skip link, one H1 per page, landmark regions and labelled sections.
  • Visible 3px copper focus ring on every interactive element.
  • Sliders are native input type="range" (arrow keys, Page Up/Down) with live aria-valuetext such as "₹50 L".
  • Accordions, tabs, dropdowns and modals use Bootstrap's keyboard support. Kanban cards move with ← / → and announce the move.
  • Calculator results are in aria-live="polite" regions.
  • prefers-reduced-motion turns off reveal, count-up and transitions.
  • Touch targets are at least 44 × 44px.

SEO & performance

  • Unique <title> (< 60 chars) and meta description (150–160 chars) on every page; canonical, Open Graph and Twitter tags.
  • FinancialService JSON-LD on every page, plus Article on the blog post.
  • sitemap.xml lists public pages; robots.txt blocks dashboards and auth pages, which also carry noindex.
  • Images are WebP with explicit width/height (no layout shift), loading="lazy" below the fold and fetchpriority="high" on hero images.
  • Scripts load with defer. Fonts use display=swap with preconnect.
  • Replace https://www.ledgerline.example everywhere with your domain before launch.
  • To push PageSpeed further: self-host fonts as WOFF2, and purge unused Bootstrap CSS with PurgeCSS.

Photos

All photographs are local files in assets/images/, so the pages make no third-party image requests. To replace one, overwrite the file (keeping the same name) or change the src in the HTML, and update the alt text. Keep the width/height attributes in step with the new image to prevent layout shift.

Banner backgrounds

The home hero, Home 2 hero, every inner-page banner, the article header, the login/register side panel and the CTA band have a full-bleed background photo. Markup: a .ll-banner section containing <div class="ll-banner-media"><img alt=""></div> (decorative, so empty alt). The overlay is drawn in CSS by .ll-banner::before: an ink-navy gradient (strong behind the text, lighter on the far side, flipped in RTL, uniform on phones). No grid lines or line drawings are drawn over photos. Banners stay dark in both themes so text contrast never depends on the photo. Tune the strength via --ll-banner-overlay in style.css section 34. If a photo can't load, the ink gradient shows on its own.

Using a CDN instead of the bundled vendor files

<link id="bs-css" rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js" defer></script>

The RTL toggle swaps the file name in the #bs-css href, so it works with CDN URLs too.

Quality checks

  • HTML checked with the W3C Nu HTML Checker: no markup errors. (Older checker builds flag fetchpriority and logical CSS properties in inline styles; both are valid in current standards.)
  • Internal links and in-page anchors verified; every image has alt; every label points to a field.
  • EMI verified: ₹50,00,000 at 8.5% for 240 months = ₹43,391.16; ₹10,00,000 at 10% for 120 months = ₹13,215.07.
  • No horizontal scrolling at 360, 390 and 768px widths.
  • Tested in Chromium. Before launch, also check Safari and Firefox on real devices.
